# LENS · KPI

> 占位骨架。后续会替换为真实 LENS 内容。

## 视角定位

KPI LENS 只做一件事：**把目标翻译成可观测的指标，并防止指标被刷成口号**。

不替代其他 LENS 的工作：
- 不定义目标（留给 goal / SMART LENS）
- 不画范围（留给 scope LENS）
- 不识别风险（留给 risk LENS，但会复用 risk LENS 输出的观测信号）
- 不分派角色（留给 actor LENS）
- 不立规矩（留给 norm LENS）

## 必答问题清单

| 类别 | 必答问题 |
|------|----------|
| **北极星指标** | 唯一一个能代表"目标达成"的指标是什么？ |
| **辅助指标** | 哪些指标共同构成"做得好"的画像？最多 3-5 个 |
| **反指标** | 哪些指标如果上升 / 下降，说明在作弊或跑偏？ |
| **采集** | 数据从哪里来？谁采、多久采、可靠性如何？ |
| **对账** | 谁负责定期对账？周期？发现偏差怎么办？ |
| **目标值** | 单位时间窗口下，预期值 / 红线值分别是多少？ |
| **退役条件** | 指标什么时候应该废止 / 重定义？ |

## 输出形式

最小输出：

1. **指标卡**：每个指标一张，包含 `名称 / 口径 / 采集 / 频率 / 目标值 / 红线 / 反指标 / 负责人`
2. **健康看板草图**：哪些指标日看、周看、月看
3. **反作弊清单**：当前能想到的"刷指标"路径与对策
4. **退役条件**：每个指标的失效情形

## 与其他 LENS 的关系

- 上游：goal / SMART LENS 锁定目标，scope LENS 划定范围，actor LENS 分派负责人之后才能定 KPI
- 平行：风险信号 ⊆ KPI 集合；规范违规率也可以是 KPI
- 下游：KPI 输出会回灌到下一轮 goal LENS（指标稳定向好 → 提升目标；持续不达 → 重审目标合理性）
