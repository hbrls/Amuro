# LENS · Actor

> 占位骨架。后续会替换为真实 LENS 内容。

## 视角定位

Actor LENS 只做一件事：**把每个动作绑定到唯一可问责的执行主体上**。

不替代其他 LENS 的工作：
- 不定义目标（留给 goal / SMART LENS）
- 不画范围（留给 scope LENS）
- 不识别风险（留给 risk LENS）
- 不立规矩（留给 norm LENS）
- 不衡量结果（留给 KPI LENS）

## 必答问题清单

| 类别 | 必答问题 |
|------|----------|
| **执行者（Doer）** | 谁实际动手做？ |
| **决策者（Decider）** | 谁有权拍板、谁可以否决？ |
| **责任者（Accountable）** | 失败时谁兜底？唯一一个人/角色 |
| **协助者（Helper）** | 谁配合？提供什么？ |
| **知情者（Informed）** | 谁需要被同步？同步到什么颗粒度？ |
| **回退路径** | 主要执行者失能时，谁顶上？切换标准是什么？ |
| **人 / Agent 划分** | 哪些动作给人？哪些给 Agent？哪些必须双签？ |

## 输出形式

最小输出：

1. **RACI 表**（或其简化版）：动作 × 角色，标注 R/A/C/I
2. **关键决策矩阵**：谁能批、谁能否决、上诉路径
3. **回退矩阵**：每个关键角色的备份与切换条件
4. **人/Agent 边界**：清单 + 一句理由

## 与其他 LENS 的关系

- 上游：scope LENS 划完边界后才能分人
- 下游：norm LENS 据此立规矩；KPI LENS 据此分摊指标；risk LENS 据此明确「谁第一时间响应」
