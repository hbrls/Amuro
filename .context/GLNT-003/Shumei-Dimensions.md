## 1. 产品定位

数美设备指纹 / smsdk 是终端设备风险能力，公开强调 100+ 原始数据维度、40+ 风险设备标签、50+ 设备属性标签、11 亿+ 设备样本库、实时动态加密算法、boxId / boxData 加密标识，以及虚假设备、机器操控、设备可疑、风险环境和行为风险识别。

iOS 侧核心应拆为四层：

- 加密设备标识：boxId / boxData，公开口径下 v3 起不直接提供明文设备标识。
- 采集控制：云配、私有化 host、代理接入、可控配置和不采集字段开关。
- 设备 / 网络 / 微行为：网络状态、代理、Wi-Fi / cell、传感器、屏幕触摸、内存扫描等能力线索。
- 服务端风险：设备农场、虚拟机、篡改设备、高危软件、全球设备风险库、图模型和风险结果。

## 2. iOS / Apple 接入方式

| 形态 | iOS 侧含义 | 稳定性判断 |
|------|-----------|------------|
| Native iOS SDK / mobile SDK | App 侧采集设备风险材料并生成加密数据 | SDK 自建材料，底层字段未公开 |
| Web / 小程序 | Web 指纹或小程序设备风险场景 | 与 Native iOS 边界需区分 |
| boxId | 服务端下发后的加密设备标识 | 准稳定厂商 ID；生命周期未公开 |
| boxData | 采集完成但未下发 boxId 前的加密数据 | 加密采集 payload，不是明文硬件 ID |
| cloudconf / 云配 | 服务端采集配置 | 控制字段、策略、host 和采集行为 |
| 私有化 / 代理接入 | 自定义 host、代理转发、海外机房 | 链路部署形态，不是设备 ID |

与 Android 对照：Android 侧明确了 `setNotCollect`、传感器、触摸、内存扫描、Wi-Fi / cell、App 列表和高危软件等能力。iOS 若公开资料没有字段级说明，只能保留能力线索和缺口，不能把 Android 权限或字段迁移为 iOS 事实。

## 3. iOS 稳定 ID 与硬件标识维度

### 3.1 公开确认的 ID / token

| 维度 | iOS 侧状态 | 结论 |
|------|------------|------|
| boxId | 公开资料确认加密标识语义 | 数美 iOS 侧最明确的准稳定设备引用；不是明文硬件 ID |
| boxData | 公开资料确认加密采集数据语义 | 加密 payload，可用于服务端生成 / 恢复标识 |
| short boxData | 公开资料有短数据策略线索 | 降低安全性或压缩字段，稳定性需追问 |
| 明文设备标识 | v3 起公开口径不直接提供 | 不应期待明文硬件 ID |

### 3.2 Apple 标识与系统能力

| 维度 | iOS 侧状态 | 结论 |
|------|------------|------|
| IDFV | 未见公开确认 | 非公开 = 仅作线索、不作结论 |
| IDFA | 未见公开确认 | iOS 17.5 下即使使用也需 ATT 授权；不能假设 |
| Keychain | 未见公开确认 | 不能把 boxId 稳定性归因于 Keychain |
| UserDefaults / App Group | 未见公开确认 | 不能写成跨安装或跨 App 持久化事实 |
| DeviceCheck / App Attest | 未见公开确认 | 可作为设备真实性和 App 完整性追问项 |
| APNs token | 未见公开确认 | token 可轮换；未确认使用 |

### 3.3 环境、微行为和风险标签

| 维度 | iOS 侧状态 | 结论 |
|------|------------|------|
| 网络连接状态 / 代理 / IP 异常 | 产品能力公开 | 网络风险维度，非稳定 ID |
| Wi-Fi / cell / 位置环境 | Android 和权限材料有线索 | iOS 字段未公开，保留缺口 |
| 加速度计 / 陀螺仪 / 姿态 | 微行为能力线索 | iOS 原始采样未公开 |
| 屏幕触摸 / View 级追踪 | `smsdk_screentouch` 线索 | 是否适用于 iOS 需确认 |
| 内存扫描 | `smsdk_mem` 线索 | iOS 可行路径未公开 |
| 模拟器 / 云手机 / 设备农场 / 多开 / 调试 / 高危软件 | 风险环境能力公开 | 服务端或 SDK 聚合风险标签 |

## 7. 当前结论

数美 iOS 侧最明确的稳定或准稳定链路是 boxId / boxData。boxId 是加密设备标识，boxData 是加密采集 payload；公开口径不支持把它们还原成明文 Apple 硬件 ID。

数美的差异化能力在云配、可控采集、微行为和服务端风险库：100+ 原始维度、40+ 风险标签、50+ 属性标签、11 亿+ 样本库、设备农场、虚拟设备、篡改设备、高危软件、异常使用习惯和图挖掘模型。iOS 字段明细未公开时，只能作为能力或缺口保留。

IDFV、IDFA、Keychain、UserDefaults / App Group、DeviceCheck / App Attest、APNs token 均未见公开确认。Android 侧的 OAID、Android ID、Wi-Fi、cell、App 列表、传感器和微行为字段不能迁移为 iOS 事实。
