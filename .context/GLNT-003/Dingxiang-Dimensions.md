## 0. 调研口径

本条目只回答顶象设备指纹在 iOS 侧可能形成的硬件标识、稳定 ID 与风控计算维度。顶象公开材料区分服务端 hardId 和客户端 token：hardId 只存在于后端服务器，token 是通讯产物；非公开 = 仅作线索、不作结论。

---

## 1. 产品定位

顶象设备指纹 UNIFYID 定位为跨 Android、iOS、Web / H5、公众号、小程序的设备唯一标识和设备风险识别能力。公开材料强调唯一设备 ID、跨浏览器稳定性、移动端抗篡改、模拟器 / 改机 / Root / 越狱 / 代理 / VPN 检测和设备画像。

iOS 侧核心是：

- 服务端 hardId：设备唯一标识只保存在后端。
- 客户端 token：客户端与服务端通讯产物，存在缓存、降级和长度区分。
- 采集控制：PrivacyFlag / 私有化 URL / 清理缓存 / 超时配置等。
- 风险检测：模拟器、虚拟机、越狱、劫持注入、代理 IP、VPN、篡改检测。
- 服务端画像：近期行为、常出现地、访问趋势和全量风险标签。

## 2. iOS / Apple 接入方式

| 形态 | iOS 侧含义 | 稳定性判断 |
|------|-----------|------------|
| DXRisk iOS SDK | iOS Native 接入设备指纹 | SDK 采集入口，底层字段未公开 |
| Web / 小程序 SDK | Web、H5、公众号、小程序指纹 | 与 Native iOS 边界需区分 |
| Mobile `/udid/m1` | 移动端接口 | token / hardId 查询链路 |
| Server SDK | Java / PHP 服务端查询 | hardId 和风险标签服务端输出 |
| 私有化 URL / 清理缓存 | 自定义 `KEY_URL`、关闭缓存 | 部署和缓存策略，不是设备 ID |

与 Android 对照：Android PrivacyFlag 字段表中有 MAC、安装包信息、GPS、蓝牙、传感器列表、内网 IP 等；iOS 公开资料未逐项确认时，只能作为同厂商追问线索。

## 3. iOS 稳定 ID 与硬件标识维度

### 3.1 公开确认的 ID / token

| 维度 | iOS 侧状态 | 结论 |
|------|------------|------|
| hardId | 公开资料确认只存在后端服务器 | 服务端设备唯一 ID，不是本地 iOS 硬件 ID |
| token | 公开资料确认为通讯产物 | 准稳定查询 / 通讯凭证，不等同 hardId |
| 24 小时缓存 token | 公开资料确认非风险环境本地缓存约 24 小时 | 本地缓存策略，不代表跨安装稳定 |
| 降级 token | 公开资料确认超时后可生成临时 token | 采集降级材料，可靠性低于服务端 token |
| token 长度区分 | 公开资料确认 size=40 / size>40 语义 | 可作为服务端生成或本地降级的判断线索 |

### 3.2 Apple 标识与系统能力

| 维度 | iOS 侧状态 | 结论 |
|------|------------|------|
| IDFV | 未见公开确认 | 非公开 = 仅作线索、不作结论 |
| IDFA | 未见公开确认 | iOS 17.5 下即使使用也需 ATT 授权；不能假设 |
| Keychain | 未见公开确认 | 不能把 token 缓存稳定性归因于 Keychain |
| UserDefaults / App Group | 未见公开确认 | 不能写成跨安装或跨 App 持久化事实 |
| DeviceCheck / App Attest | 未见公开确认 | 可作为 App / 设备真实性追问项 |
| APNs token | 未见公开确认 | token 可轮换；未确认使用 |

### 3.3 设备、网络和风险字段

| 维度 | iOS 侧状态 | 结论 |
|------|------------|------|
| GPS / 内网 IP / 蓝牙 / 传感器列表 | Android PrivacyFlag 明确，iOS 未逐项确认 | 仅作线索 |
| App 主体信息 / 应用安装列表 | Android PrivacyFlag 明确，iOS 权限边界不同 | 不能照搬 |
| 模拟器 / 虚拟机 / 刷机改机 | 移动端风险能力公开 | iOS trigger 未公开 |
| Root / 越狱 | 移动端风险能力公开 | iOS 侧应按越狱追问 |
| 劫持注入 / 代理 IP / VPN | 移动端风险能力公开 | 网络和运行时风险 |
| 31 项篡改检测 | 移动端抗篡改能力公开 | 具体字段未公开 |

## 4. 持久化路径与 SDK 自建 ID

| 路径 | 状态 | 判断 |
|------|------|------|
| hardId | 服务端持有 | 稳定性和生命周期未公开 |
| token | 客户端通讯产物 | 可缓存、可降级；不是硬件 ID |
| 本地 24 小时缓存 | 公开确认 | 不能推断跨安装稳定 |
| 降级 token | 公开确认 | 超时或服务端不可达时的临时材料 |
| PRIVATE_CLEAR_TOKEN | 私有化关闭 SDK 缓存线索 | 缓存控制能力 |
| Keychain / 本地持久化实现 | 未公开 | 非公开 = 仅作线索、不作结论 |

## 5. 服务端衍生 ID 与风险能力

| 能力 | iOS 侧归位 | 说明 |
|------|------------|------|
| hardId | 服务端设备 ID | 只存在后端，客户端拿 token |
| token 到 hardId 查询 | 服务端映射 | 映射规则和生命周期未公开 |
| 设备画像 | 服务端画像 | 近期行为、常出现地、访问趋势 |
| 全量风险标签 | 服务端风险 | 控制台可见，公开材料未展开 |
| 模拟器 / 虚拟机 / 越狱 / 注入 / VPN | 风险标签 | SDK + 服务端聚合判断 |
| 31 项篡改检测 | 抗篡改身份模型 | 对字段篡改后保持指纹稳定 |
| Web 风险识别 | Web / H5 场景 | UA、cookie、分辨率、浏览器特征、颜色深度等 |
| 跨端稳定性 | 服务端融合能力 | Web / mobile / 小程序之间的统一识别边界未公开 |

## 7. 当前结论

顶象 iOS 侧最明确的稳定链路是服务端 hardId 与客户端 token。hardId 只存在于服务端；token 是通讯产物，并存在 24 小时缓存、降级 token、长度区分、超时和私有化缓存控制。

iOS 公开资料没有确认 IDFV、IDFA、Keychain、DeviceCheck / App Attest 或 APNs token。移动端风险能力可保留为维度：模拟器、虚拟机、越狱、劫持注入、代理 IP、VPN、31 项篡改检测、Web 风险和设备画像，但不能写成具体 iOS 原始采集字段。
