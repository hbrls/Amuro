## 0. 调研口径

本条目只回答网易易盾在 iOS 侧可能形成的硬件标识、稳定 ID 与风控计算维度。公开资料确认设备指纹、风控引擎、token、配置下发和服务端画像能力，但 DNA 算法输入、SO 内部检测项和服务端标签不公开；非公开 = 仅作线索、不作结论。

---

## 1. 产品定位

网易易盾智能风控由设备指纹、风控引擎和风险画像组成。设备指纹通过 DNA 算法生成唯一设备指纹并支持智能追回；风控引擎覆盖内存修改、进程调试、模拟点击、反外挂、安全通信和本地数据加解密；风险画像覆盖账号、IP、手机号等黑灰产标签。

---

## 2. iOS / Apple 接入方式

| 形态 | iOS 侧含义 | 稳定性判断 |
|------|-----------|------------|
| 设备指纹 iOS SDK | 获取易盾设备指纹 token | SDK 主入口，底层字段未公开 |
| 风控引擎 iOS SDK | 反外挂、模拟点击、安全通信 | 风险检测入口，不是稳定 ID |
| H5 / Web / 小程序 SDK | 跨端设备指纹 | 与 Native iOS 边界需区分 |
| Server API | 在线检测、配置下发、反外挂查询 | 服务端风险输出 |
| 私有化 / 海外部署 | host、serverType、overseas、cacheTime | 部署与缓存策略 |

与 Android 对照：Android 材料中出现 IP、网络类型、启动时间、USB、电池、CPU、基带、辅助功能列表、Wi-Fi、应用包名、签名、进程名、安装包列表等。iOS 未公开逐项字段时，只能作为同厂商追问线索。

## 3. iOS 稳定 ID 与硬件标识维度

### 3.1 公开确认的 ID / token

| 维度 | iOS 侧状态 | 结论 |
|------|------------|------|
| 易盾 token | 公开资料确认设备指纹 / 风控引擎 token | 准稳定请求凭证；是否等同设备指纹需追问 |
| 离线 base64 数据 | 公开资料确认弱网 / 离线数据 | 加密采集 payload，不是稳定 ID |
| 离线 token | 公开资料确认网络不佳或超时返回 | 降级 token，可信度需追问 |
| token 缓存时间 | `setCacheTime` 等公开配置 | 缓存策略，不代表跨安装稳定 |
| DNA 唯一设备指纹 | 产品能力公开 | 服务端 / SDK 聚合 ID，输入字段未公开 |

### 3.2 Apple 标识与系统能力

| 维度 | iOS 侧状态 | 结论 |
|------|------------|------|
| IDFV | 未见公开确认 | 非公开 = 仅作线索、不作结论 |
| IDFA | 未见公开确认 | iOS 17.5 下即使使用也需 ATT 授权；不能假设 |
| Keychain | 未见公开确认 | 不能把 token 稳定性归因于 Keychain |
| UserDefaults / App Group | 未见公开确认 | 不能写成跨安装或跨 App 持久化事实 |
| DeviceCheck / App Attest | 未见公开确认 | 可作为设备真实性和 App 完整性追问项 |
| APNs token | 未见公开确认 | token 可轮换；未确认使用 |

### 3.3 风控和环境维度

| 维度 | iOS 侧状态 | 结论 |
|------|------------|------|
| IP / 网络类型 / 网络代理 | 公开采集说明有线索 | 网络风险维度 |
| Wi-Fi / 通话状态采集开关 | 公开配置线索 | iOS 可行性需确认 |
| 应用签名 / 进程名 / 应用版本 | 风控引擎必选线索 | App 完整性和上下文 |
| 内存修改 / 进程调试 / 反调试 | 风控引擎能力公开 | 运行时风险 |
| 模拟点击 / View 点击采集 | 公开 API 线索 | 行为风险 |
| 修改器 / 加速器 / 多开器 / 脚本 | 反外挂能力 | 风险标签或服务端模型 |

## 7. 当前结论

网易易盾 iOS 侧可以明确保留易盾 token、离线 base64 数据、离线 token、token 缓存、采集开关、配置下发、DNA 设备指纹、智能追回、风控引擎、模拟点击、安全通信和风险画像。它们构成 SDK + 服务端聚合能力，不等同 Apple 硬件标识。

IDFV、IDFA、Keychain、UserDefaults / App Group、DeviceCheck / App Attest、APNs token 均未见公开确认。Android 侧的 Wi-Fi、应用列表、基带、辅助功能列表、安装包列表等不能迁移为 iOS 事实，只能保留为追问缺口。
