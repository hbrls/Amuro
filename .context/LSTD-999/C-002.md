## 3. 下一轮 LENS 选型

### 3.1 候选 LENS 对照

| LENS | 适配度 | 理由 |
|------|--------|------|
| **scope** | 高 | WORKSHOP-001 链 goal → scope 的自然延续；scope 视角下方法库是「动作空间的具体填表」，与 5 项原语的组合生成天然契合。 |
| risk | 中 | 方法清单未出之前，risk 无附着对象；放后面 |
| actor | 中 | WORKSHOP-001 C-007 已配置三池 + 27 格角色矩阵，actor 在 C-002 完成后接续较合理 |
| KPI | 低 | 量化口径依赖方法清单的固化形式，需等 C-002 完成后 |
| norm | 低 | 伦理边界需等方法具体形态确定 |

### 3.2 推荐：scope LENS

- WORKSHOP-001 链已证明 goal → scope 节奏稳定（C-001 → C-003 在 WORKSHOP-001 中稳定收敛）；
- scope LENS 的产出形态（允许 / 拒绝 / 边界标注）与 C-002 的方法库枚举高度同构；
- 不重复 risk / actor 视角，让 C-002 收束后再走 risk / actor 补充。

### 3.3 scope LENS 的具体焦点

- **方法枚举**：以 5 项原语为基底，组合出 ≥ 5 个可立即调用的推进方法（不穷尽）。
- **关系矩阵**：为每对方法标注互斥 / 顺序 / 独立 中至少一种关系。
- **主方法暂定指派**：从覆盖率高或边际推进力大的方法中选 1 个作为 MR3 主线，标注「暂定 + 可轮换」并给出轮换窗口建议。
- **越界标记**：显式列出需 L2/L3 授权的方法及其越界点。
- **收束信号占位**：每方法绑定 ≥ 1 个可观测收束信号（占位符即可，KPI 数值推迟到 KPI LENS）。
- **回应 U3 / U4**：方法组合是否允许前置 + 后续链式；外部信号的边界（发邮件 / RFC / 博客 / X-Twitter 等是否纳入）。
