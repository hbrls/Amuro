## 交付结论

### CatPaw 是美团自研的全场景 AI Agent 平台，主体为云端 SaaS + 本地桌面/移动端混合形态，非工作机本地调度系统

CatPaw 定位为「全场景 AI Agent 平台」——提供开箱即用的 AI 智能工作台（桌面端、移动端、云端）与企业级 Managed Agents 开发托管能力（[美团技术博客](https://tech.meituan.com/2026/07/28/CatPaw-LongCat.html)，直接事实）。产品核心概念包括：AI 智能工作台（桌面端/移动端/云端）、Managed Agents（企业级 Agent 开发托管）、数字员工（飞书/企微 IM 集成）、专家与技能（领域能力封装）、多 Agent 协同（任务拆解与并发处理）。

对照 Index 判定基准：CatPaw 不是工作机本地调度系统。其主体能力——任务规划、多 Agent 协同、云端 7×24 运行、Managed Agents 托管——运行在美团云端平台上。桌面端和移动端是接入终端，云端模式是核心执行环境。虽然桌面端具备本地文件操作、浏览器控制和终端命令能力，但任务调度和多 Agent 协调由云端系统负责（官方文档「云端模式」节，直接事实 + 架构推导）。

### 具备有限 Stateful 调度能力：有任务拆解、多 Agent 并发调度、云端 7×24 运行，但无公开的任务对象模型、DAG 或中心调度器细节

CatPaw 的工作对象模型是 Workspace → Agent（专家/数字员工）+ Task + Skill + Memory，存在任务拆解和多 Agent 并发调度能力（官方博客「对话即交付，多 Agent 自主协同」节，直接事实）。系统能够「动态进行任务拆解，调度多个具备专属工具的 Agent 并发处理，各 Agent 在独立环境中互不干扰，进度实时可见，结果自动汇总」。

但公开资料未详细说明任务对象模型、任务间依赖关系（DAG）、任务状态机、执行归属的持久化机制，以及中心调度器的具体实现。任务拆解和多 Agent 调度是系统内部能力，未暴露为可编程的调度 API 或任务对象模型（官方文档未详细说明，架构推导 + 证据边界）。

对照 Index 调度判定基准——Stateful 调度系统必须「持久拥有工作对象、对象关系、任务状态和执行归属，并负责判断任务何时可执行、按何种顺序推进、由谁执行以及失败后如何继续」——CatPaw 展示了部分调度能力（任务拆解、多 Agent 并发、云端持续运行），但公开信息不足以确认其是否满足完整的 Stateful 调度条件。按**具备有限调度能力的任务执行宿主**记录，需进一步验证其调度对象模型和持久化机制。

### 工作对象模型：有 Workspace / Agent / Task / Skill / Memory；无公开的 Issue / Plan 持久对象细节

可辨识的持久对象（官方博客 + 文档导航，直接事实）：

- **Workspace**：工作目录，桌面端创建，包含文件和会话。
- **Agent**：AI 智能体，包括专家（领域能力封装）、数字员工（IM 集成）、自定义 Agent。
- **Task**：任务，用户通过自然语言描述目标，Agent 自主规划执行。支持长程任务和定时任务。
- **Skill**：技能，可复用的能力单元，支持浏览器操作录制生成。
- **Memory**：跨会话长期记忆，自动记忆用户偏好、操作习惯和历史上下文。
- **Session**：会话，任务执行的上下文环境。

**未公开细节**：Task 的对象模型、状态机、依赖关系、执行归属的持久化机制未在公开文档中详细说明；Issue 和 Plan 作为独立持久对象未明确提及（架构推导 + 证据边界）。

### Agent 分派是「系统动态拆解 + 多 Agent 并发」；退出/失败/断线后的恢复机制依赖云端模式

Agent 执行由用户目标触发，系统「自主规划步骤并在授权范围内深度执行」（官方博客「对话即交付」节，直接事实）。面对跨领域复杂任务，系统动态拆解并调度多个 Agent 并发处理。

云端模式支持 7×24 小时不间断运行，「即使本地设备关机或断网也不受影响。长程任务与定时任务于云端持续运转」（官方博客「全时段运行」节，直接事实）。这暗示云端具备任务持久化和恢复能力，但具体机制（检查点、重试、转移）未公开。

桌面端和移动端作为接入终端，本地设备关机或断网时云端任务继续运行，完成后可查看成果（直接事实）。

### 运行形态是云端 SaaS + 本地桌面/移动端混合；主体能力在云端，但桌面端具备本地执行能力

CatPaw 有三种运行形态（官方博客 + AIHub 评测，直接事实）：

1. **云端模式**：7×24 小时不间断运行，长程任务与定时任务在云端持续运转，本地设备关机或断网不受影响。
2. **桌面端**：macOS（Apple M 系列 / Intel）和 Windows x64 客户端，具备本地文件操作、浏览器控制、终端命令能力。
3. **移动端**：iOS 和 Android App，支持任务发起、进度查看、远程确认。

主体功能（任务规划、多 Agent 协同、云端调度）运行在美团云端。桌面端具备本地执行能力（文件操作、浏览器控制、终端命令），但任务调度和多 Agent 协调由云端系统负责。Local 优先适配判断：部分满足——桌面端具备本地能力，但核心调度和多 Agent 协同依赖云端（直接事实 + 架构推导）。

### Windows 与 macOS：均支持桌面客户端；移动端支持 iOS/Android；云端模式跨平台

CatPaw 桌面端支持 macOS 13+（Apple M 系列 / Intel）和 Windows 10+（x64）（AIHub 评测，直接事实）。移动端支持 iOS 和 Android。云端模式通过浏览器访问，跨平台。

安装方式：
- **macOS**：下载 .dmg 文件，拖拽安装。
- **Windows**：下载 .exe 安装包，按向导安装。
- **移动端**：App Store / 应用商店下载，或扫码安装。

两端均有原生桌面应用，具备本地文件操作、浏览器控制、终端命令能力（官方博客「PC 端专注本地深度执行」节，直接事实）。

### 开源与闭源边界：CatPaw 平台闭源；LongCat 2.0 模型开源

CatPaw 平台是闭源商业产品，无公开源码仓库（官方资料，直接事实）。但底层模型 LongCat 2.0 已开源（总参数 1.6T，平均激活约 48B，原生支持 1M 超长上下文）（美团技术博客，直接事实）。

外部依赖包括：飞书、企业微信（数字员工集成）、浏览器（自动化操作）、终端（命令执行）。这些依赖通过 CatPaw 平台封装，非本地独立依赖（架构推导）。

### 依赖根源：云端平台依赖美团基础设施；桌面端依赖本地操作系统能力

影响安装、运行和部署的依赖（官方资料 + 架构推导）：

- **云端**：美团云计算基础设施、LongCat 2.0 模型、飞书/企微开放平台。
- **桌面端**：macOS 13+ 或 Windows 10+（x64）、本地文件系统、浏览器、终端。
- **移动端**：iOS / Android。
- **网络**：云端模式需要网络连接；桌面端本地模式可能支持离线（未公开）。

依赖可替换性评估：CatPaw 平台闭源，不可替换；LongCat 2.0 模型开源，可自托管但需适配 CatPaw 平台接口；飞书/企微集成可替换为其他 IM 平台（需开发适配）（架构推导）。

### 架构范式判定：云端多 Agent 协同平台 + 本地执行终端，具备有限调度能力

CatPaw 的架构范式是：以云端平台为核心、以桌面/移动端为执行终端、以多 Agent 协同为任务处理模式的混合架构（官方博客 + 架构推导）。

核心组件及职责：

| 组件 | 职责 | 运行位置 |
| --- | --- | --- |
| 云端调度器 | 任务拆解、多 Agent 协同、7×24 运行 | 美团云端 |
| Managed Agents | 企业级 Agent 开发、部署、托管 | 美团云端 |
| 数字员工 | IM 集成（飞书/企微） | 美团云端 |
| 桌面端 | 本地文件操作、浏览器控制、终端命令 | 用户工作机 |
| 移动端 | 任务发起、进度查看、远程确认 | 用户手机 |
| 专家与技能 | 领域能力封装、可复用技能 | 云端 + 本地 |

通信方式：桌面端/移动端 ↔ 美团云端（HTTP/WebSocket）；数字员工 ↔ 飞书/企微（开放平台 API）；Agent 间通过云端平台协调（架构推导）。

## 产品调研

### 产品定位与目标用户

- **一句话定位**：CatPaw 是美团自研的全场景 AI Agent 平台，提供开箱即用的 AI 智能工作台（桌面端、移动端、云端）与企业级 Managed Agents 开发托管能力。
- **目标用户**：个人用户（办公提效）、本地生活商家（经营智能化）、企业团队（AI 数字员工）、Agent 开发团队（Managed Agents）（官方博客，直接事实）。
- **开源与许可**：平台闭源；LongCat 2.0 模型开源。
- **版本状态**：2026 年 7 月 28 日正式发布，已在美团内部覆盖 9 万员工、搭建 3 万个 Agent（官方博客，直接事实）。

### 核心流程

1. 用户注册 CatPaw 账号，下载桌面端或移动端。
2. 创建工作目录（Workspace），安装专家与技能。
3. 用自然语言描述任务目标，Agent 自主规划步骤。
4. 系统动态拆解复杂任务，调度多个 Agent 并发处理。
5. 桌面端执行本地操作（文件、浏览器、终端），云端执行长程/定时任务。
6. 结果自动汇总，交付 Excel、报告、代码等成果。
7. 企业用户通过 Managed Agents 创建数字员工，接入飞书/企微。

### 功能地图与边界

- **AI 智能工作台**：桌面端（macOS/Windows）、移动端（iOS/Android）、云端模式。
- **多 Agent 协同**：任务动态拆解、多 Agent 并发处理、结果自动汇总。
- **专家与技能**：专家广场、技能库、浏览器操作录制、自定义专家封装。
- **长期记忆**：跨会话记忆用户偏好、操作习惯、历史上下文。
- **Managed Agents**：企业级 Agent 开发、部署、托管、运维。
- **数字员工**：飞书/企微 IM 集成，@唤醒使用。
- **行业能力**：本地生活领域专家与技能（外卖、服务零售、医药健康等）。
- **明确不含**：公开的任务对象模型 API、DAG 依赖关系定义、自托管调度器、开源平台版本。

### 维护状态与版本演进

- **活跃维护**：2026 年 7 月 28 日正式发布，美团内部大规模落地（9 万员工、3 万 Agent）（官方博客，直接事实）。
- **关键版本演进**：
  - 2026 年 7 月：CatPaw 正式发布，搭载 LongCat 2.0。
  - 早期：CatPaw IDE（AI 编程助手，meituancatpaw.com）独立产品。
- **生态入口**：专家广场、技能库、MCP 连接器、飞书/企微集成。
- **反馈主题**：美团内部渗透率高（研发渗透率超 95%，增量代码 AI 生成率超 50%）（官方博客，直接事实）；公开用户反馈有限（社区样本，不代表整体）。

## 技术架构调研

### 系统全貌与运行形态

云端 SaaS + 本地桌面/移动端混合形态，平台闭源（官方博客 + 架构推导）：

| 组件 | 职责 | 运行位置 |
| --- | --- | --- |
| 云端调度器 | 任务拆解、多 Agent 协同、7×24 运行 | 美团云端 |
| Managed Agents | 企业级 Agent 开发、部署、托管 | 美团云端 |
| 数字员工 | IM 集成（飞书/企微） | 美团云端 |
| 桌面端 | 本地执行（文件、浏览器、终端） | 用户工作机 |
| 移动端 | 任务发起、进度查看 | 用户手机 |
| 专家与技能 | 领域能力封装 | 云端 + 本地 |

- **范式判定**：云端多 Agent 协同平台 + 本地执行终端。具备有限调度能力（任务拆解、多 Agent 并发、云端持续运行），但公开信息不足以确认完整的 Stateful 调度对象模型。

### 主要组件与核心链路

**核心链路**：用户通过桌面端/移动端/云端发起任务 → 云端调度器拆解任务 → 调度多个 Agent 并发处理（桌面端执行本地操作，云端执行长程任务）→ 结果自动汇总 → 交付成果。

跨进程/网络边界：桌面端/移动端 ↔ 美团云端（HTTP/WebSocket）；数字员工 ↔ 飞书/企微（开放平台 API）；Agent 间通过云端平台协调（架构推导）。

### 主要依赖

- **云端**：美团云计算基础设施、LongCat 2.0 模型、飞书/企微开放平台。
- **桌面端**：macOS 13+ / Windows 10+（x64）、本地文件系统、浏览器、终端。
- **移动端**：iOS / Android。
- **不可剥离的硬依赖**：CatPaw 平台（闭源）、美团云端基础设施。

### 接口形态

- **用户接口**：桌面端（macOS/Windows）、移动端（iOS/Android）、云端（浏览器）。
- **Agent 接口**：Managed Agents API（具体细节未公开）。
- **集成接口**：飞书、企业微信（数字员工）、MCP 连接器。
- **技能接口**：浏览器操作录制、自定义技能封装。

### 持久化方式

- **云端**：任务状态、Agent 配置、用户数据、记忆系统（具体数据库类型未公开）。
- **桌面端**：本地工作目录、文件系统。
- **记忆系统**：跨会话长期记忆，自动记忆用户偏好和历史上下文。

### 通信方式

- **客户端 ↔ 云端**：HTTP/WebSocket。
- **数字员工 ↔ IM**：飞书/企微开放平台 API。
- **Agent 间**：通过云端平台协调（具体机制未公开）。

### 部署形态

#### 工作机安装（Windows / macOS）

- **macOS**：下载 .dmg 文件，拖拽安装。支持 macOS 13+（Apple M 系列 / Intel）。
- **Windows**：下载 .exe 安装包，按向导安装。支持 Windows 10+（x64）。
- **依赖、权限与网络**：本地文件系统、浏览器、终端权限；网络连接（云端模式必需）。
- **卸载**：标准应用卸载流程。

#### 主体功能运行位置

- 主体功能运行在**云端**（任务调度、多 Agent 协同、Managed Agents）+ **本地**（桌面端文件/浏览器/终端操作）。
- **Local 优先适配判断**：部分满足——桌面端具备本地执行能力，但核心调度和多 Agent 协同依赖云端。

#### 云端形态

- **职责边界**：任务拆解、多 Agent 协同、7×24 运行、Managed Agents 托管、数字员工集成。
- **核心组件**：云端调度器、Managed Agents 平台、数字员工运行时、专家与技能库。
- **部署/托管**：美团官方托管，企业版支持私有化部署（官方博客「支持分级权限管控与私有化部署」节，直接事实）。
- **数据/权限/网络边界**：Agent 运行环境严格隔离，租户间数据互不可见；凭证集中托管，Agent 全程零接触敏感资产（官方博客「企业级安全」节，直接事实）。
