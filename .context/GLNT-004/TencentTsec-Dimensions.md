## 0. 整理口径

`DeviceInfoRepository` 已实现以下字段族，因此本文不再把这些字段作为腾讯云 T-Sec 缺口保留：

- `BuildInfo` 中的品牌、型号、厂商、设备代号、产品名、Android 版本、SDK 版本、主板、硬件、显示版本、Build fingerprint、Build ID、Serial。
- `RomInfo` 中的主流厂商 ROM system property，包括 MIUI / HyperOS / EMUI / Magic / OPPO / OnePlus / Realme / Vivo / OneUI / Flyme / Smartisan / LeTV / Lenovo / Nubia / Oxygen / Harmony 相关属性。
- `IdentifierInfo` 中的 OAID、Android ID / SSAID、GAID、Widevine Device ID。
- `TelephonyInfo` 中的 IMEI / MEID 合并读取、IMSI、ICCID、MSISDN、本机号码、SIM / Network operator、SIM state、SIM operator name。

腾讯云 T-Sec 公开材料中的品牌、机型、系统版本、OAID、IMEI、IMSI、SIM 卡序列号、Android ID 等基础字段，凡是已由当前代码覆盖的，不再作为缺口保留。本文只保留当前代码没有等价实现的风险标签、工具枚举、行为模型、服务端聚合 ID、关联网络和端管云防护能力。

不保留 iOS-only 字段作为 Android 实现缺口；鸿蒙 SDK 与小程序 SDK 只作为跨端资料缺口记录。

## 1. 腾讯云 T-Sec 产品定位

腾讯云 T-Sec 设备安全定位为可信设备标识 + 设备风险识别 + 服务端关联网络。公开材料强调端管云全链路安全、传感行为 AI 混合专家算法、账号 / 设备 / IP 关联网络，以及度量学习 + 无监督聚类的设备威胁态势感知。

核心能力分为七层：

| 层级 | 公开表达 | 与当前实现的差异 |
|------|----------|------------------|
| 可信设备标识 | Openid、Unionid、DeviceToken | 当前没有腾讯设备 Token、Openid 或 Unionid |
| Android 风险标签 | 公开 55 条 Android risk tag | 当前没有 T-Sec 风险标签体系 |
| 端管云防护 | 加密签名校验、自研协议、对抗重放 / 篡改 / 劫持 | 当前没有端管云协议防护 |
| 传感行为 AI | 旗舰版传感行为 AI 混合专家算法 | 当前没有人机行为识别模型 |
| 关联网络 | 账号、设备、IP 环境建立关联网络 | 当前没有设备 / 账号 / IP 图谱 |
| 威胁态势感知 | 度量学习 + 无监督聚类 | 当前没有未知风险聚类 |
| 场景化 API | login / register 场景风险、SuggestionLevel | 当前没有场景风险输出 |

与 `DeviceInfoRepository` 的差异在于：`DeviceInfoRepository` 当前主要采集 Android 本地基础标识、Build / ROM / Telephony 字段；腾讯云 T-Sec 的差异化集中在细粒度风险标签、设备篡改检测、模拟器 / 云手机 / 云真机、root / hook / 注入 / 重打包、风险应用枚举、行为异常、Openid / Unionid、关联网络聚类和实时建议等级。

## 2. Android / Mobile 接入方式

腾讯云 T-Sec 公开材料中的接入形态：

| 形态 | 说明 |
|------|------|
| Native Android SDK | V91，接入包增量约 200KB |
| Web SDK | H5 端 SDK |
| 小程序 SDK | 微信小程序端 SDK |
| 鸿蒙 SDK | 鸿蒙端 SDK |
| Server API | `DescribeFraudUltimate` / `DescribeFraudBase` / `DescribeFinanceFraudUltimate` |
| DeviceToken | 客户端 SDK 生成，服务端 API 必填 |
| SceneCode | login / register 场景输入 |
| 用户侧输入 | UserId、WeChatOpenId、QQOpenId、PhoneNumber、ClientIP、EventTime、ElapsedTime |

当前 `DeviceInfoRepository` 没有接入腾讯云 T-Sec SDK，也没有服务端 API、DeviceToken、场景风险、QQ / 微信账号关联或 DataAuthorization 链路。

## 4. 公开资料缺口

腾讯云公开材料的 Android risk tag 粒度很细，但标签背后的 evidence、阈值、服务端聚类和设备 ID 生成策略仍不透明。以下缺口应作为后续是否实现的追问项。

| # | 缺口 | 为什么重要 |
|---|------|------------|
| Q-1 | Openid / Unionid 稳定性策略 | 决定跨重装、清数据、跨账号、跨设备的连续性边界 |
| Q-2 | DeviceToken 与 Openid / Unionid 的关系 | 决定客户端 token 是否只是查询凭证还是身份锚点 |
| Q-3 | 关联网络聚类算法 | 决定账号、设备、IP 边权、阈值和社群发现策略 |
| Q-4 | 设备威胁态势感知输入 | 决定度量学习 / 无监督聚类使用哪些客户端字段 |
| Q-5 | 传感行为 AI MoE 专家分布 | 决定触控、加速度、陀螺仪、输入节奏、页面停留的覆盖范围 |
| Q-6 | OAID / IMEI / IMSI / FP 篡改检测算法 | 决定是历史画像、ROM 库、服务端一致性还是本地检测 |
| Q-7 | 群控工具识别粒度 | 决定是否基于工具包名、同 LAN、同 IP、同步行为或设备图谱 |
| Q-8 | 云模拟器 / 云手机 / 云真机区分方法 | 决定云端虚拟化和云端真机的检测 evidence |
| Q-9 | 风险应用库维护机制 | 决定木马、诈骗、涉赌、外挂、破解版等分类库的更新方式 |
| Q-10 | 端管云加密签名协议 | 决定是否使用私有协议、TLS 双向认证、消息签名、反重放 nonce |
| Q-11 | ExtraInfos 降级类型 | 决定弱网、权限缺失、SDK 降级时的字段差异 |
| Q-12 | SceneRiskInfos 场景模型 | 决定 login / register 之外是否有支付、营销、下单等模型 |
| Q-13 | QQ / 微信 OpenId 输入的关联规则 | 决定腾讯生态账号信号如何影响设备风险 |
| Q-14 | 鸿蒙 Next 容器识别边界 | 决定鸿蒙普通应用、快应用、小游戏和容器化运行时如何区分 |

## 5. 当前结论

按 `DeviceInfoRepository` 当前实现，腾讯云 T-Sec 公开材料中与品牌、型号、厂商、Android 版本、SDK 版本、ROM 属性、OAID、Android ID、GAID、Widevine、IMEI / MEID、IMSI、ICCID、运营商相关的本地基础字段不再作为缺口保留。

当前仍有价值的腾讯云 T-Sec 缺口集中在七类：

1. 设备 Token 与服务端 ID：DeviceToken、Openid、Unionid、RiskInfos、HistRiskInfos、SceneRiskInfos、SuggestionLevel、ExtraInfos。
2. 设备与身份篡改：设备信息篡改、IMEI / IMSI / OAID / fingerprint 篡改、改机工具、设备解锁、异常 / 黑灰产 / 非常见 ROM。
3. 运行时攻击：root、注入、hook、Hook 框架、重打包、调试、逆向、开发者模式、内存扫描、协议挂请求、系统劫持。
4. 虚拟化和容器：虚拟设备、主流模拟器、云模拟器、云手机、云真机、第三方多开、系统多开、多开工具、鸿蒙 Next 容器、轻应用 / 快玩环境、非系统用户。
5. 网络、位置与能力风险：客户端 IP、网络类型、VPN / HTTP 代理、VPN 工具、虚拟位置、屏幕共享、页面监听、摄像头劫持、SIM 风险标签。
6. 应用和工具库：安装风险软件、风险进程、自动化软件、群控、作弊、众包、接码、自动发卡、木马、诈骗、涉赌、涉黄、外挂、破解版、风险引流、模拟器应用。
7. 行为与服务端模型：操作事件异常、人机行为识别异常、应用刷量、团伙欺诈、多账号异常、账号 / 设备 / IP 关联网络、设备威胁态势感知、传感行为 AI MoE。
