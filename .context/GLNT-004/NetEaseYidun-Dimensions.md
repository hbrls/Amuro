## 0. 整理口径

`DeviceInfoRepository` 已实现以下字段族，因此本文不再把这些字段作为网易易盾缺口保留：

- `BuildInfo` 中的品牌、型号、厂商、设备代号、产品名、Android 版本、SDK 版本、主板、硬件、显示版本、Build fingerprint、Build ID、Serial。
- `RomInfo` 中的主流厂商 ROM system property，包括 MIUI / HyperOS / EMUI / Magic / OPPO / OnePlus / Realme / Vivo / OneUI / Flyme / Smartisan / LeTV / Lenovo / Nubia / Oxygen / Harmony 相关属性。
- `IdentifierInfo` 中的 OAID、Android ID / SSAID、GAID、Widevine Device ID。
- `TelephonyInfo` 中的 IMEI / MEID 合并读取、IMSI、ICCID、MSISDN、本机号码、SIM / Network operator、SIM state、SIM operator name。

网易易盾公开材料中的设备品牌、型号、系统版本、设备序列号、Android ID、OAID、GAID、运营商信息等基础字段，凡是已由当前代码覆盖或等价覆盖的，不再作为缺口保留。本文只保留当前代码没有等价字段、检测方法或服务端模型的设备指纹 / 风控引擎能力。

不保留 iOS-only、PC-only 字段作为 Android 实现缺口；HarmonyOS 只作为跨端资料缺口记录。

## 1. 网易易盾产品定位

网易易盾智能风控由风控引擎、设备指纹和风险画像组成。设备指纹通过 DNA 算法生成唯一设备指纹，风控引擎负责反外挂、异常检测、模拟点击识别、安全通信和本地数据加解密，风险画像用于账号 / IP / 手机号等黑灰产标记。

核心能力分为七层：

| 层级 | 公开表达 | 与当前实现的差异 |
|------|----------|------------------|
| 设备指纹 | DNA 算法、唯一设备指纹、智能追回 | 当前没有易盾设备指纹 |
| 风控引擎 | 内存修改、进程调试、模拟点击、作弊行为 | 当前没有反外挂 SDK |
| 设备信用体系 | 网易 20 年数据积累 | 当前没有设备信用评分 |
| 风险画像 | 账号、IP、手机号黑灰产标签 | 当前没有风险画像 API |
| Token 机制 | 正常 token、离线 base64 数据、离线 token | 当前没有易盾 token |
| 安全通信 | 白盒加密 + 白盒 HMAC 签名 | 当前没有安全通信协议 |
| 私有化 / 海外 | host、serverType、overseas、cacheTime | 当前没有部署策略配置 |

与 `DeviceInfoRepository` 的差异在于：`DeviceInfoRepository` 当前主要采集 Android 本地基础标识、Build / ROM / Telephony 字段；网易易盾的差异化集中在设备指纹 DNA、智能追回、风控引擎、反外挂、View 点击采集、模拟点击 AI、安全通信、本地数据加解密、应用签名 / 进程名、网络代理、CPU / 基带 / 辅助功能列表、token 缓存和离线 token。

## 4. 公开资料缺口

网易易盾公开材料覆盖设备指纹和风控引擎，但 DNA 算法、服务端标签、反外挂模型和 SO 内部字段仍不透明。以下缺口应作为后续是否实现的追问项。

| # | 缺口 | 为什么重要 |
|---|------|------------|
| Q-1 | DNA 算法输入字段 | 决定哪些字段进入设备唯一指纹 |
| Q-2 | 智能追回权重和规则 | 决定设备信息篡改后的恢复边界 |
| Q-3 | 风控引擎风险标签 | 决定服务端在线检测返回哪些标签 |
| Q-4 | 模拟点击 AI 输入 | 决定 View 点击、MotionEvent、传感器如何参与 |
| Q-5 | 反外挂 SO 内部检测项 | 决定内存修改、进程调试、加速器、多开器覆盖范围 |
| Q-6 | 安全通信协议细节 | 决定白盒加密和 HMAC 的密钥管理 |
| Q-7 | 本地数据加解密算法 | 决定游戏存档保护强度 |
| Q-8 | token 与设备指纹映射 | 决定 token 是否可跨会话稳定关联 |
| Q-9 | 离线 token / base64 数据可信度 | 决定弱网场景下的风险判断 |
| Q-10 | 设备信用体系字段 | 决定长期信用评分如何生成 |
| Q-11 | 风险画像数据来源 | 决定账号、IP、手机号黑灰产标签来源 |
| Q-12 | HarmonyOS NEXT 字段差异 | 决定鸿蒙星河版是否弱于 Android |

## 5. 当前结论

按 `DeviceInfoRepository` 当前实现，网易易盾公开材料中与品牌、型号、厂商、Android 版本、SDK 版本、ROM 属性、OAID、Android ID、GAID、Widevine、IMEI / MEID、IMSI、ICCID、运营商相关的本地基础字段不再作为缺口保留。

当前仍有价值的网易易盾缺口集中在五类：

1. 设备、系统与运行状态：IP、网络类型、启动时间、USB、充电、电池、CPU、内存 / 存储、屏幕、架构、基带、辅助功能列表、模拟器类型。
2. 网络和应用信息：BSSID、SSID、MAC、网络代理、通话状态、应用包名 / 名称 / 版本、签名、进程名、安装包列表。
3. Token 和配置：易盾 token、离线 base64、离线 token、缓存时间、采集开关、Wi-Fi / 通话开关、配置下发、海外接口。
4. 风控引擎：内存修改、进程调试、模拟点击、View 点击、修改器、加速器、多开器、反调试、防破解、游戏引擎保护、脚本保护、资源保护。
5. 服务端算法与安全：DNA 算法、智能追回、设备信用、风险画像、在线检测、白盒加密、白盒 HMAC、本地数据加解密、gameKey。
