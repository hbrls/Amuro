## 0. 整理口径

`DeviceInfoRepository` 已实现以下字段族，因此本文不再把这些字段作为数美缺口保留：

- `BuildInfo` 中的品牌、型号、厂商、设备代号、产品名、Android 版本、SDK 版本、主板、硬件、显示版本、Build fingerprint、Build ID、Serial。
- `RomInfo` 中的主流厂商 ROM system property，包括 MIUI / HyperOS / EMUI / Magic / OPPO / OnePlus / Realme / Vivo / OneUI / Flyme / Smartisan / LeTV / Lenovo / Nubia / Oxygen / Harmony 相关属性。
- `IdentifierInfo` 中的 OAID、Android ID / SSAID、GAID、Widevine Device ID。
- `TelephonyInfo` 中的 IMEI / MEID 合并读取、IMSI、ICCID、MSISDN、本机号码、SIM / Network operator、SIM state、SIM operator name。

数美公开材料提到 OAID、安卓 ID、APP 版本、设备类型、网络状态、运营商、基站、Wi-Fi、传感器、触摸事件等字段。其中已被当前代码覆盖的基础标识和 Telephony / ROM 字段不再作为缺口保留。本文只保留当前代码没有等价字段、检测方法或服务端模型的数美能力。

不保留 iOS-only 字段作为 Android 实现缺口；HarmonyOS 权限仅用于佐证传感器类能力。

## 1. 数美产品定位

数美设备指纹 / smsdk 定位为业务风险防护体系中的终端设备风险能力。公开材料强调 100+ 原始数据维度、11 亿+ 设备样本库、实时动态加密算法、多组机器学习模型、boxId / boxData 加密标识，以及虚假设备、机器操控、设备可疑、风险环境和行为风险识别。

核心能力分为七层：

| 层级 | 公开表达 | 与当前实现的差异 |
|------|----------|------------------|
| 加密设备标识 | boxId / boxData，v3 起不提供明文设备标识 | 当前没有数美加密标识 |
| 100+ 原始维度 | 软硬件特征、上网环境、设备指纹 | 当前只覆盖基础字段族 |
| 风险标签 | 虚假设备、机器操控设备、设备可疑等 40+ | 当前没有数美风险标签 |
| 设备属性 | 基础属性标签 50+ | 当前没有数美属性标签体系 |
| 微行为 SDK | `smsdk_screentouch`、`smsdk_mem` | 当前没有触摸事件和内存扫描微行为 |
| 风险环境 | 代理、调试状态、传感器状态、高危软件、设备农场、多开 | 当前没有这些环境风险检测 |
| 服务端图谱 | 设备样本库、欺诈团伙、高危群体、GCN / Node2V / Louvain | 当前没有服务端关联图谱 |

与 `DeviceInfoRepository` 的差异在于：`DeviceInfoRepository` 当前主要采集 Android 本地基础标识、Build / ROM / Telephony 字段；数美的差异化集中在加密 boxId / boxData、可控采集配置、触摸微行为、内存扫描、Wi-Fi / cell 环境、高危软件、积分墙工具、行为风险、设备样本库、服务端标签和图挖掘。

## 2. Android / Mobile 接入方式

数美公开材料中的接入形态：

| 形态 | 说明 |
|------|------|
| Native Android SDK | `smsdk*.aar`，五架构 AAR，最低 API Level 14 |
| 服务端 API | `deviceprofile/v4`、`/v3/cloudconf` |
| 私有化接入 | 支持私有化 host 和云配接口 |
| 代理接入 | 开发者自建代理服务器转发 |
| 海外接入 | 弗吉尼亚、法兰克福、新加坡等机房或代理模式 |
| 可控配置 | `SmOption.setNotCollect(Set<String>)`，示例可屏蔽 `oaid` |
| boxId / boxData | 服务器下发加密标识和采集完成后的加密数据 |
| 微行为子 SDK | `smsdk_ids`、`smsdk_screentouch`、`smsdk_mem` |

当前 `DeviceInfoRepository` 没有接入数美 SDK，也没有 boxId / boxData、云配接口、私有化 / 代理接入、可控采集配置或微行为子 SDK。

## 5. 当前结论

按 `DeviceInfoRepository` 当前实现，数美公开材料中与品牌、型号、厂商、Android 版本、SDK 版本、ROM 属性、OAID、Android ID、GAID、Widevine、IMEI / MEID、IMSI、ICCID、运营商相关的本地基础字段不再作为缺口保留。

当前仍有价值的数美缺口集中在五类：

1. 加密标识与采集链路：boxId、boxData、明文标识解密、短 boxData、`setNotCollect`、云配、私有化、代理接入。
2. 网络和环境：网络连接状态、cell 基站、Wi-Fi BSSID / SSID、代理服务器、IP 异常流量。
3. 传感器和微行为：加速度计 / 陀螺仪、移动速度、姿态稳定性、屏幕触摸事件、View 级追踪、机器操控、内存扫描。
4. 风险环境：模拟器、云手机、篡改设备、伪造设备、设备农场、多开、调试状态、高危软件、积分墙工具、设备重置。
5. 服务端标签和图谱：40+ 风险标签、50+ 属性标签、100+ 原始维度、11 亿+ 设备样本库、欺诈团伙、图挖掘、设备聚集性、异常使用习惯。
