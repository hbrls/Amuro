# WORKSHOP-004 · Flowable 6.8 → Cloudflare Workflows 迁移实验初始化

## 背景

本轮 workshop 承接前序三个 WORKSHOP 及多张澄清卡片，从高 GAP 分析阶段转向迁移实验初始化。8 项高 GAP 已全部至少完成首轮分析（C-036 确认），理论层面已排除硬阻断项。本 WORKSHOP 目标是定义最小验证实验的范围与边界。

## Goal LENS（C-037）：实验目标澄清

### 实验定义

两个阶段最小迁移实验，验证 Cloudflare Workflows 基础设施的五项基础能力：

| 实验 | 验证点 |
| --- | --- |
| 实验一：最小 Workflow 部署与运行 | 可部署 / 可启动 / 多实例并发启动 / 执行日志可观测 |
| 实验二：外部 HTTP 调用 | 在实验一基础上调用 httpbin.org/get，观察多实例并发下的外部调用行为 |

定位：**工程验证实验**，不是架构迁移。目标是以最小成本建立对 Cloudflare Workflows 基础能力的直觉与事实依据。

### 核心问题与结论

- **P0 成功标准边界**：各项验证点"完成"标准需在执行中细化，但不影响启动
- **P1 实验耦合关系**：建议顺序依赖——实验一通过后，在同一 Workflow 定义中追加 HTTP 调用能力
- **P2 产物生命周期**：复用部署产物，逐步演进，每次结束时明确验证完成状态

### 关键假设（7 项）

| 风险等级 | 假设 | 验证方式 |
| --- | --- | --- |
| 低 | A1 部署流程与 Workers 相同 | 实验一 |
| 中 | A2 并发启动不受限流影响 | 实验一 10+ 实例验证 |
| 中 | A3 日志可实时/准实时观测 | 实验一验证 |
| 低 | A4 Workflow 可发起外部 HTTP 请求 | 实验二 |
| 低 | A5 httpbin.org 可访问且返回稳定 | 实验二 |
| 中 | A6 单文件定义覆盖实验需求 | 设计中确认 |
| 中 | A7 多实例日志不混杂 | 实验一+二 |

### 未决问题（6 项）

Q1-Q6 覆盖并发度定义、日志观测方式、绑定配置、配额定价、外部鉴权、启动方式。**均不构成实验启动阻塞项**，可在执行中确定。

### Goal LENS 结论

实验目标清晰、可执行。五个理由：边界已有定义、风险可控（5 低 + 2 中）、未决不阻塞、符合用户约束、前序分析充分铺垫。**可以进入执行阶段。**
