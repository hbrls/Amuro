## 原始目标

围绕 Cloudflare Workflows 建立第一批最小迁移实验，用实践验证以下基础能力：

### 实验一：最小 Workflow 部署与运行

验证：

1. 能在 Cloudflare 上部署一个 Workflow。
2. 能启动该 Workflow。
3. 能同时启动多个 Workflow 实例。
4. Workflow 执行过程中能打日志，并能被开发者观察到。

### 实验二：外部 HTTP 调用

在实验一基础上验证：

1. Workflow 能调用 `https://httpbin.org/get`。
2. 能打印请求、响应或关键执行日志。
3. 能观察多个实例执行外部调用时的行为。

## 用户约束
