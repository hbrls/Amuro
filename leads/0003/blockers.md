# Lead 0003 - HiCash 页面业务场景分组 - Blockers

## Active Blockers

- **B-001**: HiCash 全量页面清单未知 → **需从 HiCash 技术负责人获取代码仓库访问权限，或从产品 owner 获取页面清单文档**
- **B-002**: 每个页面的业务属性未知 → 依赖 B-001 解除后逐页标注
- **B-003**: 当前 Activity / Fragment / 页面路由结构未知 → **需从 HiCash Android 代码仓库提取 AndroidManifest.xml 和路由配置**
- **B-004**: 业务场景边界尚未和业务 owner 核对 → FUP-001 已准备，待发出
- **B-005**: 哪些页面属于同一个业务闭环未知 → 依赖 B-001 + B-004 解除
- **B-006**: 技术复用页、中转页、弹窗页、结果页的归属规则未知 → 依赖 B-001 解除后逐页分类
- **B-007**: "一种场景一个 Activity"的业务接受度未知 → 需在 FUP-001 回复中确认
- **B-008**: 埋点、风控、支付、登录、Deep Link 等历史约束未知 → **需从代码仓库或数据团队获取相关配置**
- **B-009**: 优先核对或优先改造页面范围未知 → 需在 FUP-001 回复中确认
- **B-010**: 验收标准和 deadline 未知 → 需在 FUP-001 回复中确认

## Resolution Rule

每次收到新信息，只删除或更新对应 blocker。不要重写整份分析。
