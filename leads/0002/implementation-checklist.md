# Lead 0002 - 数学习题部署与呈现功能 Checklist

## Existing Capability Discovery

- [ ] 找到 AKS kanban 入口或代码路径
- [ ] 确认已实现功能列表
- [ ] 确认可复用模块
- [ ] 确认不可复用或缺失部分
- [ ] 确认现有数据结构

## Scope Definition

- [ ] 定义“部署”的最小含义
- [ ] 定义“呈现”的目标端
- [ ] 定义首批支持题型
- [ ] 定义是否支持公式渲染
- [ ] 定义是否支持图片、答案、解析
- [ ] 定义是否支持作答记录或评分
- [ ] 定义验收标准

## Minimum Functional Path

- [ ] 能创建或导入一组数学习题
- [ ] 能发布或生成可访问入口
- [ ] 能在目标端展示题干
- [ ] 能正确展示公式
- [ ] 能正确展示选项、图片或补充材料
- [ ] 能展示答案或解析，如果验收需要
- [ ] 能区分草稿、已发布、下线状态，如果部署流程需要

## Reuse Decision

- [ ] 标记 AKS kanban 中可直接复用的部分
- [ ] 标记需要改造的部分
- [ ] 标记需要新建的部分
- [ ] 给出最小实现路径

## Acceptance

- [ ] 一组真实数学习题可以被部署
- [ ] 目标用户可以打开并正确看到题目
- [ ] 公式和数学符号显示正确
- [ ] 功能边界和不支持项明确
