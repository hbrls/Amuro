# 同盾 SDK 接入 Checklist

## Before Implementation

- [ ] 确认接入端：iOS / Android / 两端
- [ ] 获取同盾 SDK 文档
- [ ] 获取 AppKey / AppId / 环境配置
- [ ] 获取测试环境
- [ ] 确认技术支持联系人或群
- [ ] 确认验收标准
- [ ] 确认上线 deadline
- [ ] 确认是否涉及服务端回调 / 事件上报 / 业务拦截
- [ ] 确认隐私合规和上架审核要求

## App Integration

- [ ] 添加 SDK 依赖
- [ ] 初始化 SDK
- [ ] 配置 AppKey / 环境
- [ ] 处理权限和隐私声明
- [ ] 在指定业务场景触发采集或上报
- [ ] 验证测试环境数据

## Server / Business Flow

- [ ] 确认是否需要服务端接口
- [ ] 确认是否需要风控结果回调
- [ ] 确认是否需要业务拦截逻辑
- [ ] 确认异常处理策略

## Acceptance

- [ ] 同盾后台可见设备 / 事件数据
- [ ] App 端无崩溃、无明显性能问题
- [ ] 权限和隐私合规通过
- [ ] 业务验收通过
- [ ] 输出接入记录
